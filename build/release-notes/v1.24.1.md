Dashboard uptime no longer resets when you reload or switch pages

- Fix: the "uptime" counter in the dashboard header reset to 00:00:00 every time you reopened the dashboard or came back from a miner's page. It was counting how long that browser tab had been open. It now shows how long Bitaxe Baller itself has been running, so it only resets when the app restarts.
- Hover the uptime counter for a short explanation. Each miner's own uptime is still shown on its card and device page.
