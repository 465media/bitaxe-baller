Block finds now detected on NerdQAxe miners

- **Fixed: a solved block on a NerdQAxe was never noticed.** Baller looked for the block counter under the name stock Bitaxe firmware uses; the NerdQAxe firmware reports it under a different name, so a real block find produced no celebration, no alert, and no entry in your block history — silently. If you run NerdQAxe hardware, this was almost certainly costing you the one notification you most want. Bitaxe and Braiins devices were never affected.
- **Block finds are also recorded at the right height now** on miners whose firmware doesn't report the chain tip — Baller fills it in from another miner on the same coin.
- Counters that reset (after a firmware wipe, say) are re-baselined instead of leaving detection stuck, so the next real find still lands.
