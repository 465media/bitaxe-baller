Lifetime blocks-found counter for every miner and your whole fleet

- **New: see how many blocks each miner has solved, lifetime, per coin.** The device page gets a "blocks found" row, e.g. "6 DGB lifetime · 2 this boot". The "this boot" count shows on NerdQAxe firmware, which keeps a separate since-boot counter.
- **New: fleet tally on the home page.** A "blocks found" tile adds up every block your fleet has solved, split by coin. Hover it for a per-miner breakdown. It stays hidden until you've found your first block.
- Baller keeps the count itself, so it survives firmware reflashes and factory resets. Miners are tracked by MAC address, so a router handing out a new IP doesn't split one miner's history. Miners you've removed from the dashboard still count toward the fleet total.
- Blocks a miner solved before Baller started watching are read from the miner's own counter the first time Baller sees it after this update. They're credited to the coin it's mining at that moment, since the firmware doesn't record which coin they were on.
- Fix: when a miner solved more than one block between two checks, only one was recorded. The full count is now saved.
- Fix: a Quai block find is now labelled "Quai" rather than "QUAI".
- Free for everyone, like the confetti.
