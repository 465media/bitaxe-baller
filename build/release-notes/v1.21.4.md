Block finds are no longer missed while Baller is closed

- **Fixed: a block solved while Baller wasn't running went unnoticed.** Your miners hash 24/7; the app doesn't. Baller worked out "did I find a block?" by comparing against a count it forgot every time it closed — so a block found overnight, or while the app was shut, was quietly absorbed and never celebrated. It now remembers each miner's count between sessions and tells you on the next launch, labelled *found while Baller was closed* so the timestamp isn't mistaken for when it actually happened. This is real, not theoretical: it cost us a genuine DigiByte block.
- Fresh installs still won't fire for blocks you found before installing Baller, and a miner that's been reset or reflashed re-baselines quietly instead of celebrating an old block twice.
